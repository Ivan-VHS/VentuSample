# Dak naming canon

Dak is the operating-system name and canonical system identity. Use `Dak` for user-facing references and `dak` / `dakos` only where a lowercase technical namespace is required by the owning contract.

Reaper, Pytyliki, OPlague and VentuSample remain independent product identities with their own responsibilities. Do not prepend `Dak` to product names, package IDs or executable names unless a specific cross-system contract requires it.

Avoid animal, water, pond, feather and sound-effect metaphors in product names, technical terminology and interface decoration. Prefer clear functional names and explicit domain language.

The shared identity must not override accessibility, native platform behavior, security boundaries or each product's established information architecture.
