# Hip-Hop Preset Crate

These four starter presets use the existing ventusample.preset.v1 contract. They are original parameter starting points for the current offline generator, not sampled recordings, artist emulations or claims about source clearance.

| Preset | Lane | Starting pocket |
|---|---|---|
| east-coast-pocket-93.json | East Coast loop | 93 BPM, 58% swing |
| boom-bap-crate-88.json | Boom Bap loop | 88 BPM, 62% swing |
| g-unit-knock-93.json | G-Unit loop | 93 BPM, 56% swing |
| golden-era-chop-90.json | Golden Era loop | 90 BPM, 60% swing |

## Load a preset

Open the VentuSample desktop workstation, choose the preset load action and select one of these JSON files. The workstation validates the preset contract and applies the supported parameters. Choose your own source WAV in the interface; these presets do not bundle or fetch third-party samples.

Every preset fixes its seed so the same supported settings can be rendered again. Edit the settings or seed to create a new beat pass. Output remains offline PCM16 WAV with the existing pack metadata.

These settings are starting points, not mastering targets. Audition every print and make the final mix decisions by listening.
