# Dak design canon

Dak is the operating-system identity. Shared interface guidance must remain functional, accessible and native to each host toolkit; it must not impose one product's information architecture on another.

Dak system surfaces use the black, white and gold foundation. Success, warning, error and information colors remain semantic status roles and are always accompanied by labels or icons. Product-specific applications retain their own established visual identity unless a shared system surface is explicitly in scope.

Use readable contrast, visible keyboard focus, native controls, reduced-motion behavior and opaque work surfaces for precision tasks. Avoid animal, water, pond, feather or quack metaphors in product names, technical terminology and interface decoration. No external runtime assets or cloud fonts are required.
