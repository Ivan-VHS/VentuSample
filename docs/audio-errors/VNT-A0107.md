# VNT-A0107 — Low-pass cutoff out of range

**Severity:** error · **Status:** active

The low-pass cutoff must be greater than the configured high-pass cutoff and lower than 0.49 times the input sample rate. The limit leaves a margin below Nyquist for the current processing path.

**Typical causes**
- The cutoff is above the supported range for the selected sample rate.
- The low-pass cutoff is equal to or lower than the high-pass cutoff.
- The source file uses a lower sample rate than expected.

**How to fix it**

Choose a cutoff above the high-pass value and below `0.49 × sample_rate`. At 44,100 Hz, the upper bound is 21,609 Hz.

This diagnostic documents the current processing contract; it is not a universal limit for every filter.
