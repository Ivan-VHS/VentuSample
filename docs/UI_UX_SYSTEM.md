# VentuSample UI/UX System

**Status:** implemented Qt 6 desktop workbench with light/dark theme, scrollable generator, offline worker-thread rendering and result/log tabs.

## Product surface

VentuSample is a procedural sample-pack workstation, not a DAW, plugin host or live audio monitor. The generator is the primary workflow; Results/Log and About are separate tabs. Keep sound identity, musical structure, groove/texture, master/motion, optional source WAV and export grouped in that order.

## Visual language

- Use the shared white-blue-red Anatidae palette and semantic tokens in [ANATIDAE_DESKTOP_DESIGN_SYSTEM.md](ANATIDAE_DESKTOP_DESIGN_SYSTEM.md).
- Keep cards and editors opaque, readable and compact. Use the water/feather vocabulary only through subtle section hierarchy, dividers and state feedback.
- Use blue for primary creation and focus, red for meaningful danger/emphasis, and no independent teal/amber/green/violet brand palette.
- Use persistent field labels, explicit units and visible current values; do not rely on placeholders or color-only status.
- Keep the generator scrollable until responsive reflow is verified on supported window sizes.

## Interaction

- **Create Sample Pack** is the primary action; destination selection is separate and visible.
- While rendering, disable duplicate generation, display a readable busy state and keep the window responsive.
- Results remain selectable/openable; logs are read-only and bounded.
- Source WAV import is optional and explicitly identified as PCM16; imported material remains local.
- Theme controls affect appearance only, not musical settings, seed, sample rate or generated bytes.

## Platform and accessibility

| Environment | Direction | Boundary |
|---|---|---|
| Windows | Qt 6 native widgets, Segoe UI, keyboard-visible focus | Primary desktop target |
| Linux | Qt 6 native widgets using platform defaults with semantic theme fallback | Desktop target where Qt 6 is available |
| macOS | Qt 6 native widgets using platform defaults | Build/runtime behavior must be validated on the target OS |

Targets are 44 logical px where practical. Preserve keyboard traversal, tab order, readable disabled states, selectable paths/logs, reduced-motion behavior and contrast in both themes.

## Anatidae grammar

The supplied lexical family means clear entry, stable identity, fluid grouping and restrained geometry. It does not mean a cartoon duck, novelty status names or animated water backgrounds. The complete word-to-design mapping and VentuSample-specific requirements are maintained in the design authority.

## Validation checklist

- Light/dark themes use the canonical palette and focus is visible.
- Parameter ranges, units, values and output paths remain readable while resizing.
- Generator remains responsive during offline rendering.
- Existing deterministic seed behavior, PCM16 WAV contracts, manifest schema and no-overwrite policy remain unchanged.
- UI wording never implies live playback, device capture or online telemetry.
