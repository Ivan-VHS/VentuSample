# Project stewardship

| Principle | Gate |
|---|---|
| Creative intent | controls have documented musical/technical purpose |
| Repeatability | seed, parameters and output are reproducible |
| Evidence | separate metrics from subjective listening |
| Ownership | source rights and manifest contracts are explicit |
| Incident | stabilize → assess → contain → communicate → recover → review |
| Credibility | no false artist association, rights, sales or quality claims |

For DSP, musical controls, metadata or licensing changes record parameters, sample rate, channel layout, tests, listening notes, limitations and rollback.
