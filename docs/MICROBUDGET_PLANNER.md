# Планировщик микробюджета 500 грн

## Что реализовано

Планировщик распределяет заданный лимит между шестью категориями: продукты и питание, транспорт, быт и здоровье, связь и обучение, досуг и кофе, резерв. Категории и суммы можно менять; приложение пересчитывает общую сумму, остаток и превышение лимита без округления и без скрытых комиссий.

## Сценарии

| Сценарий | Продукты | Транспорт | Быт | Связь/учёба | Досуг | Резерв | Итого |
|---|---:|---:|---:|---:|---:|---:|---:|
| Недельный баланс | 280 | 120 | 0 | 0 | 50 | 50 | 500 |
| Продуктовый минимум | 500 | 0 | 0 | 0 | 0 | 0 | 500 |
| Транспортный запас | 0 | 500 | 0 | 0 | 0 | 0 | 500 |
| Кофе и перезагрузка | 0 | 0 | 0 | 0 | 460 | 40 | 500 |
| Бытовой рефилл | 0 | 0 | 500 | 0 | 0 | 0 | 500 |
| Инвестиция в себя | 0 | 0 | 0 | 500 | 0 | 0 | 500 |
| Резерв | 0 | 0 | 0 | 0 | 0 | 500 | 500 |

Сценарий — лишь стартовый шаблон: после его выбора суммы остаются редактируемыми. Если план превышает лимит, приложение показывает точную величину превышения, не обрезая пользовательские значения.

## Справочные ориентиры

Включены предоставленные в статье ориентиры: эспрессо около 46 грн; крупы и макароны; мука, хлеб, молоко, яйца, картофель, яблоки, курица и куриное филе; указанные там примеры тарифов Киева, Днепра и Львова. Диапазоны сохраняются как диапазоны.

**Важно:** эти цены взяты из пользовательского текста, не проверялись как текущие предложения магазинов или транспортных операторов и должны редактироваться перед реальным планированием. Планировщик не загружает котировки, не обращается к банковским счетам и не отправляет телеметрию.

## Запуск

```text
Откройте VentuSample → меню «Планирование» → «Планировщик бюджета 500 грн…».
```

## Формула

`остаток = лимит − сумма распределений`

Если остаток отрицательный, модуль показывает `превышение = −остаток`. Проценты использования рассчитываются только для ненулевого лимита.
