# Language and editorial quality

**Canonical shared specification:** [DAK — Language and editorial quality](https://github.com/Ivan-VHS/DAK/blob/main/docs/LANGUAGE_QUALITY.md).

Apply the shared editorial principles to English, Ukrainian, Russian and Simplified Chinese documentation, UI text, diagnostics and release notes. Preserve audio terminology, units, format names and sample-ownership statements; automated prose checks do not replace contextual review.
