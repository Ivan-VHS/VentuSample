# Improvement and conflict standard

Use the machine-readable 20×3 profile for evidence-backed quality changes.

| Step | Gate |
|---:|---|
| 1 | reproduce audible/technical issue |
| 2 | define expected output and parameters |
| 3 | patch on a branch with rollback |
| 4 | add deterministic regression |
| 5 | validate WAV, schema and QMR |
| 6 | review before merge |

Vocabulary labels are not proof that a defect exists.
