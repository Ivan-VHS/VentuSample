# Unified Documentation and Semantics Standard

**Canonical specification:** [DAK — Unified Documentation and Semantics Standard](https://github.com/Ivan-VHS/DAK/blob/main/docs/UNIFIED_DOCUMENTATION_STANDARD.md).

Use the shared maturity vocabulary, runtime-state definitions, evidence hierarchy and README publication checklist. VentuSample source, tests, manifests, schemas and CMake configuration remain authoritative for audio behavior and build support.

The shared policy includes 50 publication checks covering repository identity, release provenance, architecture/contracts, breaking changes, limitations, reproducible metrics, localization, link navigation, legal attribution and clean-environment verification. See [Documentation Control](DOCUMENTATION_CONTROL.md) for audio-specific gates.
